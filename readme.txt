# pixelIdentify 使用文档

## 简介

pixelIdentify 是一个用于分析视频文件中指定区域颜色变化的Python脚本。它可以检测视频中特定区域的颜色变化，并记录颜色发生变化的时间点。

## 依赖安装

### 1. 安装Python依赖

```bash
# 安装必需的Python包
pip install opencv-python numpy

# 或者使用conda
conda install opencv numpy
```

### 2. 系统要求

- Python 3.6+
- 支持的视频格式：MP4, AVI, MOV, MKV等常见格式

## 使用方法

### 基本语法

```bash
python pixelIdentify.py [选项] 视频文件路径
```

## 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `video_path` | 必需 | - | 视频文件路径 |
| `-t, --threshold` | int | 30 | 颜色变化检测阈值 (0-255) |
| `-s, --sample-rate` | int | 1 | 采样率，每隔多少帧检测一次 |
| `-x, --center-x` | int | 画面中心 | 检测区域中心x坐标 |
| `-y, --center-y` | int | 画面中心 | 检测区域中心y坐标 |
| `-b, --block-size` | int | 10 | 检测区域大小（正方形边长） |
| `--no-progress` | flag | False | 不显示进度信息 |

## 参考指令

### 1. 基本使用

```bash
# 分析视频，默认参数（画面中心，10x10像素区域）
python video_color_analyzer.py video.mp4
```

### 2. 自定义检测区域位置

```bash
# 在指定坐标(300, 200)处检测
python video_color_analyzer.py video.mp4 -x 300 -y 200
```

### 3. 自定义检测区域大小

```bash
# 使用20x20像素的检测区域
python video_color_analyzer.py video.mp4 -b 20
```

### 4. 调整颜色变化敏感度

```bash
# 设置较低的阈值，检测更细微的颜色变化
python video_color_analyzer.py video.mp4 -t 15

# 设置较高的阈值，只检测明显的颜色变化
python video_color_analyzer.py video.mp4 -t 50
```

### 5. 提高处理性能

```bash
# 每5帧检测一次，提高处理速度
python video_color_analyzer.py video.mp4 -s 5
```

### 6. 组合使用多个参数

```bash
# 在坐标(638, 337)处检测10x10区域，阈值为20，每1帧检测一次
python3 pixelIdentify.py /Users/stanleysun/Downloads/20251102-204914.mp4等5个文件/20251102-224431.mp4 -x 638 -y 337 -b 10 -t 20 -s 1
```

### 7. 不显示进度信息

```bash
# 静默模式运行
python video_color_analyzer.py video.mp4 --no-progress
```

## 参数详细说明

### 阈值 (-t, --threshold)
- 范围：0-255
- 数值越小越敏感，能检测到更细微的颜色变化
- 数值越大越严格，只检测明显的颜色变化
- 默认值：30

### 采样率 (-s, --sample-rate)
- 每隔指定帧数检测一次
- 值为1时每帧都检测（最准确但较慢）
- 值为n时每隔n帧检测一次（提高性能但可能遗漏细节）
- 默认值：1

### 检测区域坐标 (-x, -y)
- 指定检测区域的中心坐标
- 如果不指定，默认为画面中心
- 坐标超出画面范围时会自动调整

### 区域大小 (-b, --block-size)
- 检测区域为正方形，此值为边长
- 值越大检测区域越大，结果更稳定但精度降低
- 值越小检测区域越小，结果更精确但可能受噪声影响
- 默认值：10

## 使用建议

1. **性能优化**：对于长视频，建议使用较高的采样率（如-s 5或更高）
2. **精度调整**：根据需要调整阈值，检测细微变化用低阈值，检测明显变化用高阈值
3. **区域选择**：选择颜色变化明显的区域进行检测
4. **大文件处理**：处理大文件时建议使用--no-progress参数减少输出干扰

## 故障排除

### 常见问题

1. **无法打开视频文件**
   - 检查文件路径是否正确
   - 确认视频格式是否支持
   - 检查文件是否损坏

2. **进度显示异常**
   - 某些视频格式可能无法正确获取总帧数
   - 可以使用--no-progress参数关闭进度显示

3. **检测不到颜色变化**
   - 降低阈值参数（-t）
   - 调整检测区域位置和大小
   - 确认视频中确实存在颜色变化
